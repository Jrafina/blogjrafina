三、列表

  • 无序列表

    使用 -、+ 或 * 作为标记

    - 项目1
    - 项目2
      - 子项目2.1
      - 子项目2.2

  • 有序列表

    使用数字 +. 作为标记

    1. 第一步
    2. 第二步
       1. 第二步的子步骤1
       2. 第二步的子步骤2
    3. 第三步

  • 任务列表

    使用 - [ ] 表示未完成，- [x] 表示已完成

    - [x] 已完成任务
    - [ ] 未完成任务
    - [ ] 待办任务

    • 已完成任务

    • 未完成任务
