Windows 应用完全手动卸载指南

教程归纳 • 上传时间：2025-12-07

概述

当Windows应用无法通过正常方式卸载，或卸载后仍有残留时，需要手动彻底清理。本教程将详细指导您如何完全手动卸载应用，包括文件、注册表、服务等所有残留。

⚠️ 警告：手动修改注册表和系统文件有风险，请务必先创建系统还原点或备份重要数据。

一、准备工作

1.1 创建系统还原点

1. 按 `Win + R` 打开运行对话框
2. 输入 `sysdm.cpl` 并回车
3. 转到"系统保护"选项卡
4. 点击"创建"按钮，按提示创建还原点

1.2 备份注册表

1. 按 `Win + R`，输入 `regedit` 打开注册表编辑器
2. 点击"文件" → "导出"
3. 选择"全部"，保存为备份文件（如 registry_backup.reg）

三、手动删除残留文件

3.1 程序安装目录

检查并删除以下目录中的相关文件夹：
1. `C:\Program Files\`
2. `C:\Program Files (x86)\`
3. `C:\ProgramData\`（隐藏文件夹，需开启显示）
4. `C:\Users\Public\`

3.2 临时文件

清理临时文件：
1. `%TEMP%` 或 `C:\Windows\Temp`
2. `C:\Users\[用户名]\AppData\Local\Temp`

四、清理注册表残留

4.1 打开注册表编辑器

1. 按 `Win + R`，输入 `regedit`
2. 按 `Ctrl + F` 打开搜索框

4.2 搜索并删除相关项（按F3继续搜索）

需要搜索的关键位置：


1. **应用设置和配置**：
   - HKEY_CURRENT_USER\Software\[开发商名或应用名]
   - HKEY_LOCAL_MACHINE\SOFTWARE\[开发商名或应用名]


2. **64位系统额外检查**：
   - HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\[开发商名或应用名]


3. **启动项**：
   - HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
   - HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Run


4. **文件关联**：
   - HKEY_CLASSES_ROOT\Applications\[应用名].exe
   - HKEY_CLASSES_ROOT\[应用相关扩展名]


5. **卸载信息**：
   - HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\
   - HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\
