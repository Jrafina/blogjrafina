Tips总结

  • 清理DNS污染指令： ipconfig /flushdns 命令行指令
  • 配置清华源： pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple pip指令
  • 删除右键注册表： 计算机\HKEY_CLASSES_ROOT\Directory\Background\shell\ 注册表清理
  • （键盘失能）管理员身份打开命令行： sc config i8042prt start= disabled 键盘失能
  • （键盘使能）管理员身份打开命令行： sc config i8042prt start= demand 或者 auto 键盘使能
  • 进入python虚拟环境的指令：.venv\Scripts\activate Python
