博客搭建及托管

教程归纳 • 上传时间：2025-11-28

一、搭建流程概览

1.软件及账号准备 ——> 2.安装Hexo和链接github账号 ——> 3.创建本地Hexo项目 ——> 4.托管至github ——> 5.托管至couldfare

二、软件及账号准备

- 软件篇

接下来，我们检查一下git和Nodejs是否安装成功

点击Git Bash Here，

注意：在Git Bash Here里面的所有复制粘贴操作均需要按鼠标右键执行，不能用ctrl+c,ctrl+v等快捷键

输入:
node -v
git -v

如果出现版本号就算安装成功

接下来我们npm换源，用于下载加速，按下win+R,输入cmd,点击确定，在命令行里面输入：

npm config set registry https://registry.npmmirror.com

无报错则安装完成！

- 账号篇

准备一个github账号即可，couldfare可以用github账号登录

打开steam++(也就是watt toolkit,下文直称steam++)，开启加速

注册github账号 github官网,点击sign in

创建github仓库，用于储存hexo文件

注册后创建仓库名格式必须为：<用户名>.github.io，完成后点击create repository，这样我们的仓库就创建好了(此处设置的仓库是public类型的)

三、安装Hexo和链接github账号

- 安装Hexo

打开Git Bash Here，输入：

npm install -g hexo-cli

进行安装，之后运行

hexo -v

验证是否安装成功

- Github部署

在Git Bash Here中运行

git config --global user.name <你的用户名>
git config --global user.email <你的邮箱>

运行以下代码检查是否配置成功

git config -l

- 连接至 GitHub

接着运行

ssh-keygen -t rsa -C <你的邮箱>

直接按几次回车生成ssh密钥，用于此电脑连接至 GitHub

之后打开C盘用户文件夹下的.ssh的文件夹，用记事本打开 id_rsa.pub，复制里面的内容

然后在github主页，点右上角头像 > Settings > SSH and GPG keys > New SSH key

Title随意，Key粘贴刚刚复制的密钥，之后点Add SSH key

运行以下代码测试连接，出现连接到账户至此环境部署完成

ssh -T git@github.com

成功如图

四、创建本地Hexo项目

任意创建一个文件夹，里面用于存放Hexo项目，这里我创建my_blog文件夹

在blog文件夹里面点击鼠标右键，进入Git Bash Here，输入：

npm i
hexo init

你的my_blog文件里里面出现以下文件

之后输入：

hexo c;hexo g;hexo s

注意：这个段命令作用是，清理缓存（c）,产生网页（g）,本地构建博客内容(s)

!

浏览器打开 http://localhost:4000/ 测试网站，出现以下界面说明Hexo项目创建成功，按下ctrl+c停止

五、托管至github

在Git Bash Here中输入以下内容，用于安装 hexo-deployer-git

npm install hexo-deployer-git --save

在my_blog文件夹内，修改 _config.yml 文件 deploy 部分（文件最下面）,之后保存

deploy:
  type: git
  repository: git@github.com:<用户名>/<用户名>.github.io.git
  branch: main

运行以下命令，将代码部署到 GitHub，执行hexo d时候也要关闭steam++

hexo cl; hexo g; hexo d
